# English OS

A private, local-first Business English study application guided by *Market Leader Intermediate (3rd Edition)*.

## Run

Open `index.html` in a modern browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

The initial release includes a responsive dashboard, the 12-unit curriculum, an original Unit 1 grammar/vocabulary practice set, a study journal, and local progress tracking. Other course units are listed as planned, not misrepresented as complete.

## Privacy

Progress is saved in this browser's `localStorage`; no account or remote sync is used. Export a backup from Progress regularly. The original copyrighted textbook is **not** bundled in this repository.

## Scope

This repository is separate from `plataforma-ingles-uso-personal`, which remains unchanged. Future iterations can migrate proven components selectively.
